### About me

I'm a **Software Engineer at Data Kernels** (since Feb 2026), where I build AI systems for US healthcare clients.

- Working on an **LLM document-intelligence platform** that turns 1,500+ page medical case files into structured reports, supporting **400+ reports a month** and cutting turnaround from **4-5 days to 3-4 hours**.
- Day to day: **FastAPI** backends, **n8n** orchestration, **multi-agent LLM pipelines** (Gemini, Claude), OCR, and **hallucination checks** before anything reaches a user.
- Outside work I build **end-to-end ML projects**: clean data, honest evaluation, tracked experiments, and a model you can actually call.
- B.Tech in Computer Science (Data Science), 2026. **Oracle OCI Data Science Professional** certified. Published research in **IJSTM**.

### Featured projects

| Project | What it is | Stack |
|---|---|---|
| 🚕 **[TripIQ](https://github.com/KrishnaPVispute/TripIQ)** | NYC taxi trip-time (ETA) prediction on 1.4M trips. Deep EDA, time-based split, 17 models compared, tuned gradient boosting, experiments and model registry on DagsHub, data versioned with DVC, served through an API and UI | Python, scikit-learn, LightGBM, MLflow, DVC, FastAPI, Streamlit, Docker |
| 💬 **DataGen** | Ask business questions in plain English and get correct, read-only SQL plus a short answer. Graph-based RAG over a Neo4j context graph, a self-correcting SQL loop and a 27-question accuracy test suite | Python, FastAPI, Neo4j, MySQL, Claude, Ollama, Docker |
| 💎 **Diamond Price Prediction** | Modular ML pipeline (ingestion, transformation, training) with tuned regression models, deployed as a Flask app on AWS Elastic Beanstalk | Python, scikit-learn, Flask, AWS |
| 🌱 **Crop Disease Detection** | MobileNet CNN that classifies crop-leaf diseases from photos and suggests treatment. Published research paper (IJSTM) | Python, TensorFlow, Keras, Flask |
